# Employee Directory Management System

## 1. Project Information

Project Name:
Employee Directory Management System

Project Type:
Web-Based Application

Development Methodology:
Software Development Life Cycle (SDLC)

Development Model:
Waterfall Model


## 2. Project Background

Employee Directory Management System is a web-based application designed to help organizations manage and organize employee information efficiently.

Many small businesses still rely on manual records or spreadsheet files to store employee data. While these methods can work for a small number of employees, they can become difficult to manage as the number of records increases.

This project aims to provide a centralized system where users can easily store, view, update, and manage employee information through a simple and user-friendly interface.


## 3. Problem Statement

Managing employee information manually can lead to difficulties in organizing, searching, and updating records.

The following problems were identified:

- Employee information is scattered across different files or documents.
- Searching for specific employee records can take time.
- Updating employee information manually may cause inconsistencies.
- There is no centralized system for managing employee records.


## 4. Proposed Solution

The proposed solution is to develop a web-based Employee Directory Management System that allows users to manage employee records in a centralized database.

The system will provide basic employee management features such as adding, viewing, editing, deleting, searching, and filtering employee information.

The application will use PHP as the backend language and MySQL as the database to store and manage employee records.


## 5. Project Objectives

### General Objective

To develop a simple and user-friendly web-based Employee Directory Management System that improves the management of employee records.


### Specific Objectives

- To create a system that allows users to view employee records.
- To implement functionality for adding new employee information.
- To provide features for updating and deleting employee records.
- To develop a search function for easier retrieval of employee information.
- To implement department filtering for better organization of employee data.
- To store employee information using a MySQL database.

## 6. Scope and Limitations

### Scope

The system will include the following features:

- Display employee records.
- Add new employee records.
- Edit existing employee information.
- Delete employee records.
- Search employees by name.
- Filter employees by department.
- Store employee data in a local MySQL database.

### Limitations

The system will not include the following features:

- User authentication and login system.
- Employee attendance monitoring.
- Payroll management.
- Leave management.
- Email notifications.
- Online/cloud database.

## 7. Target Users

- HR Staff

- Small Business Owners
